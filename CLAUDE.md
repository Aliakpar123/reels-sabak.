# Тегін сабақтар (лендинг)

Одностраничный сайт на казахском языке с бесплатными видеоуроками по Reels. Он работает на GitHub Pages: https://aliakpar123.github.io/reels-sabak./

Владелец пишет с телефона, по-русски и коротко. Отвечай по-русски, без технических подробностей. Каждую правку доводи до сайта сам, не перекладывай шаги на владельца.

## Файлы
- `index.html`: вся страница. Разметка, стили и скрипт в одном файле, без сборки и зависимостей.
- `oferta.html`, `privacy.html`, `terms.html`: страницы документов из подвала.
- `.github/workflows/deploy.yml`: при каждом push в `main` копирует сайт в ветку `gh-pages`, а GitHub Pages её публикует.

## Что где менять
Почти всё, что владелец обычно хочет поменять, лежит в объекте `CONFIG` внизу `index.html`:
- `authorName`: имя в карточке-профиле, `authorPhoto`: ссылка на фото (если пусто, в кружке первая буква имени);
- `ctaText`: текст кнопки, `contactUrl`: куда ведёт кнопка (Telegram или WhatsApp);
- `lessons`: список уроков, `{ title, youtubeId }`. ID берётся из ссылки YouTube: `youtu.be/<ID>` или `watch?v=<ID>`;
- `freeLessons`: сколько первых уроков открыто бесплатно, на остальных стоит замок. Открытие после оплаты ещё не сделано: ID видео пока лежат прямо в коде страницы;
- `accessHours`: сколько часов уроки доступны с первого визита (таймер хранится в localStorage);
- `copyright`: строка в подвале.
Заголовок, тексты и цифры «12 Reels» и «50K+» в профиле записаны прямо в HTML. Число уроков (в профиле и в блоке «Барлық N сабақты аш») скрипт берёт сам из длины `lessons`.

## Как публиковать
1. Внеси правку и сделай коммит.
2. Изменения должны попасть в `main`. Если сессия работает в отдельной ветке, создай PR и смержи его, или сделай fast-forward `main`. Владелец ждёт, что правка появится на сайте без его участия.
3. Workflow сам обновит `gh-pages`, сайт обновится через 1–2 минуты. Статус проверяй через Actions API: из облачной среды github.io недоступен.

## Стиль
Креатор-студия, всё на мотивах Reels и Instagram: сверху закреплённая полоска «● REC» с таймером, карточка автора как профиль Instagram, плеер в рамке видоискателя, прогресс полосками как в сторис, уроки сеткой 3×5 как в ленте (на компьютере 5 колонок), внизу тёмный блок с призывом. Заголовки набраны шрифтом Unbounded, основной текст — Onest. Цвета: фон `#eceef3`, текст `#0f1222`, один акцент — синий `#2f45ff`, красный `#ff3b30` только для REC. Градиенты не добавляй. Сначала мобильная вёрстка: проверяй на ширине около 390px. Все тексты на сайте на казахском.
